# Sync engine design

Status: revision 5, after the review of d37ee0d and its delta reviews. The core design (the three trees, commits, disk application and the mass-delete guard) is final. The recovery of §6.4 and the recovery parts of §10 are a **draft, to be verified by simulation**: the named scenarios of §7.5 must pass before 0.1.0. Paragraphs marked **[changed]** differ from the design approved at that commit; the list is in [Changes from the approved draft](approved-draft-changes.md#changes-from-the-approved-draft). Scope: `core/engine` (the sync state machine), `core/sim` (the simulation harness and reference server) and the parts of `core/chunk` the engine relies on. Protocol references such as "spec §6.2 R3" point to the v0 protocol draft that `spec/proto` implements.

# Sync engine reference

This page lists the rules of the sync engine (`core/engine`) and of the drivers that carry out its decisions (`core/fs`, `core/driver`, `core/store`), under the section numbers that code, tests and RFCs cite. [Sync engine design](../sync-engine.md) explains how the parts fit and why. "Spec §n" is the v0 protocol that `spec/proto` implements, "RFC nnnn" is a file in `spec/rfc/`, and R1 to R11 are the server's conflict rules of spec §6.2.
